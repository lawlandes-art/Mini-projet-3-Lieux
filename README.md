 # Mini-projet 3 Lieux — Comparaison de trois îles
 
 
 Site web statique multi-pages réalisé dans le cadre du module de **maquettage et intégration web** (titre professionnel Développeur Web / Web Mobile).<br>
 Choix libre des lieux.<br>
 Le projet compare trois îles — **Jeju**, **l'Islande** et **Hawaï** — à travers une page d'accueil et une page dédiée par destination.
 
 
 
 🌐 **Voir le site en ligne :** [https://lawlandes-art.github.io/Mini-projet-3-Lieux/](https://lawlandes-art.github.io/Mini-projet-3-Lieux/)
 ## Objectifs du projet
 
 
 * Concevoir une maquette graphique cohérente sur **Figma** et **Canva** avant l'intégration.
 * Développer un site multi-pages en **HTML5** et **CSS3** (avec `normalize.css` et feuilles de styles dédiées).
 * Proposer une charte visuelle et une structure éditoriale harmonisées sur l'ensemble des pages.
 * Mettre en place des **ancres de navigation interne** (`#culture`, `#cuisine-locale` / `#cuisine locale`, `#divertissements`) pour naviguer rapidement vers les thématiques de chaque lieu.
 * Illustrer chaque destination avec des visuels cohérents et des contenus informatifs structurés.
 
 
 ## Structure du projet
 
 
 ```text
 Mini-projet-3-Lieux/
 ├── index.html             # Page d'accueil et présentation comparative des 3 lieux
 ├── index.css              # Styles spécifiques à la page d'accueil
 ├── page_1_jeju.html       # Page dédiée à l'île de Jeju
 ├── page_2_islande.html    # Page dédiée à l'Islande
 ├── page_3_hawai.html      # Page dédiée à Hawaï
 ├── style.css              # Feuille de style principale des pages destinations
 ├── normalize.css          # Normalisation des styles par défaut des navigateurs
 ├── images_accueil/        # Visuels de la page d'accueil
 ├── images_jeju/           # Visuels dédiés à Jeju
 ├── images_islande/        # Visuels dédiés à l'Islande
 └── images_hawai/          # Visuels dédiés à Hawaï
 
 ```
 
 
 ## English Overview
 
 
 This static multi-page website was built as part of a **Web Design and Front-End Integration** training module (Web & Mobile Web Developer certification). It compares three volcanic islands — **Jeju**, **Iceland**, and **Hawaii** — through a landing page and one dedicated page per destination.
* **Live demo:** [https://lawlandes-art.github.io/Mini-projet-3-Lieux/](https://lawlandes-art.github.io/Mini-projet-3-Lieux/)
* **Design & Prototyping:** Wireframes and UI mockups created with **Figma** and **Canva**.
* **Technologies:** Semantic **HTML5**, **CSS3** (`normalize.css` + custom stylesheets), and internal anchor navigation (`#culture`, `#cuisine-locale`, `#divertissements`).
* **How to run locally:** Clone the repository and open `index.html` in any modern web browser.
